GitHub

Без сервера MLingo может хранить прогресс и решения прямо в твоём GitHub repo. Для этого нужен fine-grained token с доступом Contents: Read and write к одному репозиторию.

GH
GitHub не подключен Сохрани локальный GitHub token или войди через backend OAuth позже.
Как это будет работать
  • Serverless mode создаст или использует mlingo-solutions.
  • Прогресс сохраняется в progress/mlingo-progress.json.
  • После write/fix/idea задач решение пушится markdown-файлом в solutions/.
  • Разборы и уведомления появятся позже, когда будет backend.
